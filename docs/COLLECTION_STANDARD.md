# 2026 法考主观题持续收集规范

核验截止：2026-09-05

## 收录边界

1. 纯客观选择题不得进入主观题正文。
2. 主客观一体材料只有在能够独立形成“结论—规则—涵摄”的法律陈述时，才能进入“主观化训练”，并与纯主观每日一题分开统计。
3. 只发现课程名、合集名或账号页，尚未定位题目与答案单篇页的，进入渠道中心，不计入已收录题数。
4. 受登录、付费、App 或平台风控限制的内容，只通过公开搜索、公开转载和机构官网寻找线索，不绕过访问控制。

## 每题必填字段

- 唯一 ID、题型、科目、争点和发布时间。
- 机构、老师、平台、栏目及内容性质。
- 原题单篇链接、公布答案单篇链接及最后核验日期。
- 完整训练题面、明确设问、发布者答案要旨。
- 本库完整答案：结论、规则、事实涵摄、争议分支和落笔压缩版。
- 纯主观 / 主客观一体主观化标签、版权说明和版本记录。

## 来源等级

- P0：官方或中央、国家机关权威资料。
- P1：老师本人公开发布。
- P2：机构官方公开发布。
- P3：能够与原发内容交叉核验的可靠转载。
- P4：搜索摘要、索引或不稳定线索；只能用于发现，不能单独证明题目和答案已完整核验。

## 增量更新节奏

- P0 核心老师与高频栏目：每 1—2 日复核。
- P1 已确认连续更新栏目：每 2—3 日复核。
- 其余候选渠道：每周复核；发现新系列后提升优先级。
- 每次更新先补单篇来源与答案状态，再更新题面和作答，不用不完整占位稿冒充成品。
